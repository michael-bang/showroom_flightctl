= 3. Edge Manager - Software Catalog

In the prior module we saw how you can add configuration, applications and monitor systemd services. 
Many organizations have people providing and managing the devices, other people in charge of the applications and then
some people using the applications on the devices. 

This is what the *sotware catalog* is for.

Edge Manager uses a software catalog to organize and distribute versioned software components for edge devices. 
The catalog provides a structured way to publish applications, system images, and other deployable content, track 
their versions, and define upgrade paths between them.

The catalog consists of two types of resources:

*Catalog:* A named grouping of catalog items. For example, you might have a catalog called platform-apps for core platform 
applications and another called infrastructure for infrastructure components.
*CatalogItem:* A versioned entry within a catalog representing an application, system image, or other deployable component. 
Each item defines its type, artifacts, configuration, and one or more versions with upgrade paths.
